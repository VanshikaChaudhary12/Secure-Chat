# Quick Deploy Guide

## 🚀 Fastest Deployment Options

### 1. Render (Easiest - Free Tier)

**Time: 5 minutes**

1. Push your code to GitHub
2. Go to https://dashboard.render.com
3. Click "New +" → "Blueprint"
4. Connect your GitHub repo
5. Render auto-detects `render.yaml`
6. Add environment variables:
   - `MONGODB_URI`: Get free MongoDB from https://www.mongodb.com/cloud/atlas
   - `CORS_ORIGIN`: Will be auto-generated by Render
7. Click "Apply"

**Done!** Your app will be live at `https://your-app.onrender.com`

---

### 2. Railway (Fast - Free Tier)

**Time: 3 minutes**

```bash
# Install Railway CLI
npm i -g @railway/cli

# Login
railway login

# Deploy
railway init
railway up
```

Add MongoDB: `railway add` → Select MongoDB

**Done!** Railway provides the URL automatically.

---

### 3. Docker (Local/VPS)

**Time: 2 minutes**

```bash
# Clone and navigate
cd secure-chat

# Deploy
chmod +x deploy.sh
./deploy.sh
```

**Done!** Access at `http://localhost`

---

### 4. Vercel (Frontend Only)

**Time: 2 minutes**

```bash
cd frontend
npm install -g vercel
vercel
```

For backend, use Render or Railway.

---

## Environment Variables Needed

### Backend
- `MONGODB_URI` - Get from MongoDB Atlas (free)
- `JWT_SECRET` - Any random string (auto-generated in scripts)
- `CORS_ORIGIN` - Your frontend URL

### Frontend
- `REACT_APP_API_URL` - Your backend URL

---

## Free MongoDB Setup

1. Go to https://www.mongodb.com/cloud/atlas
2. Create free cluster (M0)
3. Create database user
4. Whitelist IP: `0.0.0.0/0` (allow all)
5. Get connection string
6. Use in `MONGODB_URI`

---

## Troubleshooting

**CORS Error?**
- Update `CORS_ORIGIN` in backend to match frontend URL

**Can't connect to DB?**
- Check MongoDB URI is correct
- Ensure IP whitelist includes `0.0.0.0/0`

**Build fails?**
- Run `npm install` in both frontend and backend
- Check Node version (need 16+)
